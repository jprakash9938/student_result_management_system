File Structure Guidelines

The uploaded Excel file must have a header row as the first row. The system reads records starting from Row 2.

Required Columns (Order and names matter):

  1. Column A: Roll Number (must match student roll number)
  2. Column B: Subject Code (must match subject code)
  3. Column C: Semester (integer between 1 and 8)
  4. Column D: Marks (numeric between 0 and 100)
